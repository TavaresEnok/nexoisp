# Lote 41 — marca opcional no portal

O recorte integra nome opcional e logotipo privado normalizado por provedor, configuráveis por usuário autorizado e exibidos no portal autenticado. Sem configuração, mantém-se o nome do provedor; a identidade fiscal não muda. Os cenários usam raster sintético próprio. Não há personalização global, ativos externos ou integração Chatwoot.

As três raízes de formatação, API e interface constam do histórico integrado sobre 8461e61. Este trabalho prepara o registro das rotas, o contrato nativo e a fumaça. Revisão independente e gate combinado continuam pendentes da gerência; compilar ou preparar testes não comprova PostgreSQL, navegador ou CI. O lote 40 permanece DONE 5/5 e teve HTTP real exit 0 em 8461e61; a execução Go/PostgreSQL em andamento pela gerência não possui recibo de conclusão aqui. Pendências externas e corte financeiro permanecem inalterados.
